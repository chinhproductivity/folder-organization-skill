## Chi Tiết Từng Workflow

### 🚀 1. First-Time Setup
**Dành cho:** Người lần đầu muốn tổ chức folder lộn xộn  
**Các bước chính:**
1. Xác định mục đích (cá nhân/dự án/doanh nghiệp)
2. Thu thập thông tin folder
3. Chọn quy chuẩn đặt tên
4. AI khảo sát & đếm file
5. AI đề xuất cấu trúc mới
6. User xác nhận → AI thực hiện
7. Verify không mất file

---

### 🔄 2. Periodic Cleanup
**Dành cho:** Folder đã tổ chức, cần dọn dẹp định kỳ  
**Các bước chính:**
1. Xác nhận folder đã tổ chức
2. AI quét file mới/lỗi
3. User xác nhận từng nhóm hành động
4. AI thực hiện dọn dẹp
5. Báo cáo hoàn thành

**Tần suất gợi ý:** Hàng tuần/tháng

---

### 📦 3. Archive Old Files
**Dành cho:** Giải phóng folder chính, lưu trữ file cũ  
**Các bước chính:**
1. Thiết lập tiêu chí (thời gian, loại file)
2. AI quét file đủ điều kiện
3. User xác nhận danh sách
4. AI archive + tạo log
5. Hướng dẫn khôi phục nếu cần

---

### 🔗 4. Sync Structure
**Dành cho:** Áp dụng cấu trúc chuẩn cho nhiều folder  
**Các bước chính:**
1. Chọn folder mẫu/template
2. Xem trước cấu trúc
3. Chọn folder đích
4. AI so sánh & bổ sung
5. Tùy chọn lưu template mới

---

### 🆕 5. New Project Setup
**Dành cho:** Tạo nhanh cấu trúc khi bắt đầu dự án mới  
**Templates có sẵn:**
- 💼 Kinh doanh
- 💻 Phát triển phần mềm
- 🎨 Creative/Thiết kế
- 📣 Marketing Campaign

**Các bước chính:**
1. Nhập thông tin dự án
2. Chọn template phù hợp
3. Tùy chỉnh nếu cần
4. AI tạo cấu trúc + README

---

## Quy Tắc Chung

⚠️ **Tất cả workflows đều tuân thủ:**
- KHÔNG xóa file - chỉ di chuyển
- LUÔN đếm file trước/sau để verify
- LUÔN hỏi user xác nhận trước khi thực hiện
- TẠO log/backup khi cần
