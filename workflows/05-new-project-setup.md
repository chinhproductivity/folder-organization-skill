# 🆕 Workflow 5: Tạo Folder Mới Cho Dự Án (New Project Setup)

## Mục Đích
Tạo nhanh cấu trúc folder chuẩn khi bắt đầu dự án mới, đảm bảo:
- Có đầy đủ folder cần thiết từ đầu
- Tên folder theo quy chuẩn
- Có file README/INDEX hướng dẫn

---

## Bước 1: Thông Tin Dự Án

**AI hỏi:**
```
🆕 THÔNG TIN DỰ ÁN MỚI:

📝 Tên dự án: ___
📂 Vị trí tạo folder: ___

🎯 Loại dự án:
1. 💼 Kinh doanh / Business
2. 💻 Phát triển phần mềm / Software
3. 🎨 Thiết kế / Creative
4. 📚 Nghiên cứu / Research
5. 📣 Marketing / Campaign
6. 🔧 Khác (mô tả)

Chọn:
```

---

## Bước 2: Chọn Template Phù Hợp

**AI đề xuất dựa trên loại dự án:**

### Template: Kinh Doanh
```
[Tên_Dự_Án]/
├── 01_Ke_Hoach/              # Kế hoạch, chiến lược
├── 02_Tai_Lieu/              # Tài liệu dự án
├── 03_Hop_Dong/              # Hợp đồng, pháp lý
├── 04_Tai_Chinh/             # Báo cáo tài chính
├── 05_Bao_Cao/               # Báo cáo tiến độ
├── 06_Truyen_Thong/          # Marketing, PR
├── 98_Templates/             # Mẫu biểu
├── 99_Archive/               # Lưu trữ
└── README.md
```

### Template: Phát Triển Phần Mềm
```
[Tên_Dự_Án]/
├── 01_Requirements/          # Yêu cầu, specs
├── 02_Design/                # Thiết kế, mockups

├── 05_Deployment/            # Deploy, release
├── 06_Documentation/         # Docs
├── 98_Assets/                # Resources
├── 99_Archive/               # Lưu trữ
└── README.md
```

### Template: Creative / Thiết Kế
```

├── 01_Brief/                 # Brief, yêu cầu
```

### Template: Marketing Campaign

```
1. Mở README.md để cập nhật thông tin
```
